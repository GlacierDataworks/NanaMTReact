Nana of Montana\n=================\n\nThis project aims to create a platform for connecting people to their Nanas.\n\n## Frontend\nBuilt with React and TypeScript, using Vite for building and serving.\n\n## Setup\n1. Install dependencies: `npm install`\n2. Run the application: `npm start`\n\n## Backend\nBuilt with ASP.NET Core 9.0. Please refer to the backend documentation for details.
